CLI

Simple commands

Run termcute for the animated picker, or use subcommands for scripted use.

terminal 
termcute                              # animated picker
termcute list                         # list built-in themes
termcute apply <slug>                 # apply a theme permanently
termcute custom-image <path>         # normalize and apply image
termcute custom-image --clipboard    # paste from clipboard
termcute restore                      # restore original settings
